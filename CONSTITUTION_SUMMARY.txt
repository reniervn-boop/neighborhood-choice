🔧 INTEGRATION FOR DEVELOPERS:

Import and use Constitution utilities:

  import {
    canVoteInMeeting,
    canStandForCommittee,
    calculateQuorum,
    isPayingMember,
    getMembershipStatusSummary,
    transitionToPayingMember,
    isSpecialResolutionPassed
  } from '@/lib/constitution';

Examples:

  // Check if user can vote
  if (canVoteInMeeting(user)) {
    // Show voting interface
  }

  // Calculate meeting quorum
  const quorum = calculateQuorum(totalPayingMembers);

  // Check if special resolution passed (75% for amendments)
  if (isSpecialResolutionPassed(votesFor, votesAgainst, votesAbstain)) {
    // Amendment passed
  }

  // Get formatted status
  const status = getMembershipStatusSummary(user);
  // Returns: { status, icon, description, canVote, canStandForOffice, isGoodStanding }
